## Stemme og tone

- **Språk:** Norsk bokmål, kort og tydelig
- **Målgruppe:** Sjåfører og flåteeiere som vil forstå hva som driver dieselprisen
- **Tone:** Faktabasert, forklarende, ikke selgende
- **Viktig:** Vi er ikke tilknyttet drivstoffkjeder. Tall er veiledende, ikke prisgarantier.

## Innholdstyper

1. **Nyheter** – Del artikler fra /nyheter med kort oppsummering
2. **Forklart** – Pedagogisk innhold om prissammensetting, avgifter, OPEC, valuta
3. **Markedsoppdatering** – Korte observasjoner om bevegelser i råvarepris, valuta, avgifter
4. **Engasjement** – Spørsmål og avstemninger om diesel/drivstoff
